# English Adventure (working title)

A mobile-first English-learning adventure. **The product name is not yet selected.**

This repository starts with the approved product rules, A0.0 contract, art dossier, and folders reserved for reference artwork. The image reference files have not yet been committed. It intentionally contains no speculative application implementation. Codex should follow `AGENTS.md` and begin with EA-001.

## Governing references

1. `docs/GAME_RULEBOOK.md` — product rules
2. `docs/A0_0_PRODUCT_AND_CONTENT_CONTRACT.md` — first episode requirements
3. `docs/ART_DIRECTION_DOSSIER.md` — art direction (some details provisional)
4. `AGENTS.md` — engineering and agent protocol

The bedroom, protagonist, and kitchen image references remain in the downloadable starter ZIP and should be imported separately into `public/references/` before visual implementation; they are not yet in this repository. The mascot is the protagonist’s dog; its final design remains undecided.

Open this repository in Codex, ask it to read `AGENTS.md`, and assign only EA-001.
