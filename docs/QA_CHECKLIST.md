# Vertical Slice QA Checklist

## Product
- [ ] New learner can select support language and start English study.
- [ ] Preferred name is remembered, editable, and shown correctly.
- [ ] Dog companion is presented as guide, not an unrelated animal.
- [ ] First lesson makes its narrative objective and educational objective clear.
- [ ] Story progression and language mastery are separate.

## Learning
- [ ] English audio precedes assessment of unfamiliar utterances.
- [ ] Translations appear at appropriate support level; learner may request them again.
- [ ] Wrong answers get helpful feedback and a retry without penalties.
- [ ] Speaking is optional and unscored.
- [ ] No false CEFR certification or inaccurate mastery claims.

## UX and engineering
- [ ] 320px mobile width and typical phone viewports work without overflow.
- [ ] Keyboard focus, accessible labels, and sufficient contrast.
- [ ] Back/forward, refresh, and audio-failure states do not strand user.
- [ ] Lesson content is data-driven, not embedded directly in UI components.
- [ ] No secrets committed, no unexpected services or paid integrations.
- [ ] Build/tests/lint run and their outcomes are reported.
